l'utilisateur. Les usages sont ceux du Brand Board NOVART et des PDF de règles.

Les logos primaire et submark sont copiés à l'identique. Le fond blanc rosé uni du logo
secondaire (utilisé dans l'application) a été rendu transparent, sans toucher aux lettres.
Les anciens extraits du PDF de mascotte en 477 × 399 et 1116 × 760 ont été retirés des
interfaces : leurs fichiers sources étaient trop petits pour les écrans haute densité.
L'application et le site vitrine utilisent maintenant les illustrations HD ci-dessus.
Les copies réservées au site vitrine se trouvent dans `landing/assets/img/`.

Le nom accessible du lien d'accueil reste « Novart, accueil » ; les images y sont
décoratives pour éviter une lecture redondante par les lecteurs d'écran.
